# Настройка Telegram бота

Это руководство поможет вам создать Telegram бота и получить ID чата для настройки конфигурации.

## Создание бота в Telegram

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Начните диалог с ним, отправив команду `/start`
3. Создайте нового бота, отправив команду `/newbot`
4. Следуйте инструкциям BotFather:
   - Введите имя для вашего бота (например, "Server Management Bot")
   - Введите username для вашего бота (должен заканчиваться на "bot", например, "server_mgmt_bot")
5. После создания бота вы получите токен в формате `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`
6. Сохраните этот токен - он потребуется для настройки конфигурации бота

## Получение ID чата

Для получения ID чата (пользователя или группы), с которым будет взаимодействовать бот, выполните следующие шаги:

### Для приватного чата (личные сообщения):

1. Напишите любое сообщение боту, которого вы создали
2. Откройте браузер и перейдите по следующему URL (замените `YOUR_BOT_TOKEN` на токен вашего бота):
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
3. В ответе JSON найдите секцию `message` -> `from` -> `id`
4. Это и будет ID чата пользователя

### Для группового чата:

1. Добавьте бота в группу
2. Напишите в группу любое сообщение
3. Откройте браузер и перейдите по следующему URL (замените `YOUR_BOT_TOKEN` на токен вашего бота):
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
4. В ответе JSON найдите секцию `message` -> `chat` -> `id`
5. Это и будет ID группового чата (они обычно отрицательные)

## Настройка конфигурации

После получения токена бота и ID чата, обновите файл `config-server.yaml`:

```yaml
telegram:
  token: "YOUR_BOT_TOKEN"
  chat_id: YOUR_CHAT_ID
```

Где:
- `YOUR_BOT_TOKEN` - токен, полученный от @BotFather
- `YOUR_CHAT_ID` - ID чата, полученный через getUpdates API

## Дополнительные настройки

### Настройка приватности бота (для групповых чатов)

Если вы используете бота в групповом чате, рекомендуется настроить приватность:

1. Вернитесь к @BotFather
2. Отправьте команду `/mybots` и выберите своего бота
3. Выберите "Bot Settings" -> "Group Privacy"
4. Выберите "Turn off" - это позволит боту видеть все сообщения в группе

### Настройка команд бота

Вы можете настроить список команд для вашего бота:

1. Вернитесь к @BotFather
2. Отправьте команду `/mybots` и выберите своего бота
3. Выберите "Edit Bot" -> "Edit Commands"
4. Отправьте список команд в формате:
   ```
   start - Запустить бота
   help - Справка по использованию бота
   ```

После выполнения этих шагов ваш бот будет полностью настроен и готов к использованию.
